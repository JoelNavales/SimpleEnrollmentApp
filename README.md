# SimpleEnrollmentApp
This is a Flutter application designed to help students register for multiple courses. Students first enter their personal information, then select the courses they want to enroll in. The app allows them to review their selected courses before confirming their enrollment. It uses Provider for state management, which ensures that the student data and course selections are consistently shared across different screens in the app. The user interface is simple and intuitive, making it easy for students to navigate through the registration process. this is viewed using Pixel 9 pro andriod device
